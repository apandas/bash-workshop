Windows does not include a Unix shell by default. You will need to install Git for Windows (often referred to as Git Bash), which provides both Git and a Bash shell in one program.

2a. Download the Git for Windows installer.
2b. Run the Git Bash installer. Work through each screen using the settings below:

b1. Click Next on the Information, Location, Components, and Start Menu settings. You don't need to change any default values for these.
b2. From the dropdown menu, Choosing the default editor used by Git, select Use the Nano editor by default. Then click Next.
b3. On the setting Adjusting the name of the initial branch in new repositories, verify that Let Git decide is selected. This will ensure the highest level of compatibility for the module.
b4. Ensure that Git from the command line and also from 3rd-party software is selected, then click Next.
⚠ This setting must be selected. If it is not, Git Bash will not function correctly and you will need to uninstall and reinstall the program.
b5. Select Use bundled OpenSSH.
b6. Select Use the native Windows Secure Channel Library, then click Next.
b7. Select Checkout Windows-style, commit Unix-style line endings, then click Next.
b8. Select Use Windows' default console window,, then click Next.
b9. Select Default (fast-forward or merge), then click Next.
b10. Select Git Credential Manager, then click Next.
b11. Select Enable file system caching, then click Next.
b12. Click Select.
b13. Click Finish or Next

2c. Now you will need to configure your home folder by telling Git Bash where your home folder is located on your computer. To do this, open the Command Prompt (Open the Start Menu then type cmd and press Enter) and follow the steps below:

c1. Type the following line into the Command Prompt window exactly as shown: setx HOME "%USERPROFILE%"
c2. Press Enter, you should see SUCCESS: Specified value was saved.
c3 Type exit and press Enter to close the Command Prompt.

2d. Verify your Git Bash installation by following the steps below:

d1. Open Git Bash from the Start Menu.
d2. Type the following line into the Git Bash window: bash --version
d3. Press Enter. You should see the window returns GNU bash, version 5.2.X or similar. Your Git Bash installation and setup for the module is complete. See step 3.

Bash is available in all versions of macOS. Follow these steps to verify that Bash is your default shell, and change it if needed.

2a. Open the terminal app on your computer. You can locate it at /Applications/Utilities, or by searching for “terminal” using Spotlight (⌘ Space).
2b. Type the following line into your terminal window exactly as shown: echo $SHELL
2c. Press Enter. If the output ends with /bash (for example /bin/bash), then continue to step 2e to verify your Bash shell. If it does not, continue to the next step.
2d. Type the following line into your terminal window and press Return: chsh -s /bin/bash
⚠ You may be prompted to enter your login password. Type it and press Return, the cursor will not move while you type.
2e. Reboot your computer, then continue onto step 2f.
2f. Verify your Bash shell by following the steps below:

f1. Open your terminal and type the following line: bash --version
f2. Press Return. You should see your terminal return GNU bash, version 5.2.X or similar. If you have version 5.X.X, then your setup for the module is complete. See step 3.
